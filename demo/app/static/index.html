The problem

Why squeeze a neural network?

Real-time particle-physics triggers decide what's worth keeping under a hard, nanosecond-scale time budget and a sliver of on-chip hardware — a full-precision network usually doesn't fit.

~40M collisions / second

The solution

Shrink the numbers, not the network

Quantization keeps the architecture fixed and reduces the numerical precision of its weights and activations — then this project measures exactly where that trade-off breaks.
